KitchenHub v2.0 — Target Architecture

Multi-vendor Marketplace Platform on Cloudflare Edge
Phase 1: Foundation Phase 2: Marketplace Phase 3: AI Intelligence

Phase 1: Foundation (Weeks 1-4)

  • Extract commerce-core npm package (Cart, Product, Order, PaymentGateway)
  • D1 Schema v2: vendors, commissions, tenants, webhooks, audit_logs
  • Tenant middleware: subdomain routing, feature flags, KV config
  • GitHub Actions matrix: preview/PR, staging/main, production/tag
  • Cloudflare Preview URLs for every PR

Phase 2: Marketplace (Weeks 5-8)

  • Vendor API: register, dashboard, product CRUD, order management
  • Vendor Portal (React Islands): drag-drop images, earnings, payouts
  • Commission engine: configurable rates, daily cron, Stripe Connect/SSLCommerz payouts
  • Admin Dashboard: vendor approval, analytics, commission management
  • Security: vendor isolation, rate limits, load test (100 VUs), audit logging

Phase 3: AI Intelligence (Weeks 9-12)

  • Vectorize index: 768-dim embeddings (BAAI/bge-base-en-v1.5)
  • Workers AI: edge inference <50ms, batch embedding jobs
  • Hybrid Recommender: content (0.6) + collaborative (0.4)
  • Personalization API: /api/ai/personalize?user_id=Y
  • Sanity CMS + ISR: Blog, Recipes, Buying Guides, SEO
  • Observability: OpenTelemetry → Grafana Cloud, SLOs, alerting

Platform KPIs (v2.0 Targets)

  • P99 Latency: <500ms global
  • Error Rate: <0.1%
  • Build/Deploy: <3 min / <2 min
  • Vendors: 20+ by Week 12
  • Products: 500+ listed
  • GMV: $50K+/mo
  • Commission Revenue: $7.5K+/mo
  • Recommender CTR: >15% lift
  • Uptime: 99.9%

Security & Compliance

  • PCI DSS SAQ-A (Stripe/SSLCommerz handle cards)
  • GDPR/PDPA: data export, deletion
  • Vendor KYC before payouts
  • Rate limiting: per vendor, IP, endpoint
  • Audit logging: all admin/vendor actions
  • Secrets rotation: quarterly, automated
  • Dependabot + npm audit CI
  • Pen test: Week 8, annually

Team & Budget

  • 4 Skill Agents + 1 Human Orchestrator
  • Agent-1: Backend Architect (claude-code)
  • Agent-2: Frontend Engineer (claude-code)
  • Agent-3: Data/AI Engineer (codex)
  • Agent-4: Platform/DevOps (hermes-agent)
  • Monthly cost at scale: ~$200-400
  • 12 weeks / 12 sprints
  • Go/No-Go: Week 12 criteria
